## 硬性要求

1. **先假设、后实验**：填写"提出时间"后立刻提交，`git log` 时间即为留痕证据；
2. 每条必须写**推翻判据**（出现什么数据算假设不成立）；
3. 核验后逐条填写第 6 节结论（支持 / 推翻 / 修正），不能留空；
4. 编号与 `README.md`、报告表 1、报告附录 B **三处必须一致**。
