# 假设 C1：关闭合并后空闲块数随释放次数持续上升、碎片迅速恶

- 提出人：史一飞 2024612031
- 提出时间：待填（须早于实验运行与模型咨询，以 git 提交时间为证）
- 负责人分工：释放与合并测试

## 1. 假设表述

关闭合并后空闲块数随释放次数持续上升、碎片迅速恶化；开启合并可抑制但不能消除外部碎片。

## 2. 理由

每次释放新增一块空闲区；合并只作用于相邻块，被已分配区隔开的两块永远合不到一起。

## 3. 预期现象

关合并版空闲块数单调不减且明显高于开合并版，失败次数更多。

## 4. 检验方式

- 输入：`experiments/inputs/case2-merge-all.json、case3-fragmentation.json`
- 操作：同一序列跑「合并开 / 合并关」两版，记录空闲块数曲线与失败次数；并用案例 3 第 8、9 步检查全释放后能否恢复为单块。
- 记录：`experiments/traces/`、报告表 1

## 5. 推翻判据

关闭合并后空闲块数不增；或开启合并后外部碎片可被完全消除。

## 6. 核验结论

- 判定：**支持**
- 证据位置：
  - `experiments/traces/merge-onoff.json`：同一案例 3 序列，第 9 步合并开时空闲块数 1，合并关时 4
  - `experiments/traces/merge-onoff.json` 中 `merge_off` 的 `merged_check` 全为 `false`，
    说明"合并完整"检查能识别出未合并的相邻块
- 差异出现的位置与原因：关闭合并后每次释放新增一块，且相邻块不再吸收，块数单调上升；
  但即使开启合并，案例 3 第 6 步仍然失败，说明合并不能消除外部碎片
