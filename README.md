# 连续内存分配与碎片问题验证

操作系统原理课内实践项目 · **第 12 组** · **题目五** · 指导教师：吴俊豪

> 研究问题：空闲内存总量足够时，为什么一次**连续**内存申请仍可能失败？
> 最佳适应（Best Fit）依据什么标准作选择？它"最佳"在哪里，又差在哪里？

本项目通过一个可交互的网页模拟器，实现**首次适应（First Fit）**与**最佳适应（Best Fit）**
两种连续内存分配策略，以及释放时的**相邻空闲区合并**，用三组对照实验展示
**外部碎片**导致"总量够、连续块不够"的申请失败现象，并完成人工推演核对。

## 二、快速开始

```bash
# 演示网页：无第三方依赖，直接用浏览器打开
open web/index.html          # macOS（或双击文件）

# 重新生成全部实验数据（需要 Node.js）
node tools/gen-traces.js
node tools/probe-criterion.js
node tools/buggy-demo.js
node tools/search-counterexample.js 20261127 16

# 编译报告（需要 XeLaTeX）
cd report && make
```

**在线演示**：部署到 Cloudflare Pages 后填写
`https://<你的项目>.pages.dev`（部署方法见 docs/00 第 X 节）

## 三、实验复现步骤

1. 打开演示网页，选择预置案例（或输入自定义操作序列）；
2. 切换策略（首次适应 / 最佳适应），点击"运行"或"单步"；
3. 对照 `experiments/traces/` 中的原始输出核对逐步布局与指标；
4. 用 `experiments/hand-simulation/` 的人工推演表核对至少一组序列；
5. 输入格式约定见 `experiments/inputs/README.md` 与 docs/02。

## 报告模板（LaTeX）

小组报告用 `report/` 下的 LaTeX 模板（个人分析不提供 LaTeX 模板，直接写在 `individual/` 目录的 Markdown 中），版式基线取自学校论文模板库
`Paper_Library/计算方法实验报告模板`（XeLaTeX + ctex），详见 `docs/05-报告模板说明.md`。

章节骨架与评分维度对应：摘要 → 模型构建（假设与约束）→ 算法实现 → 实验设计 →
结果与分析 → 结论与局限 → 附录（程序代码 / 小组分工 / AI 工具使用说明）。

```bash
cd report
make                    # xelatex 跑两遍，生成 report-template.pdf
make clean              # 清理 aux/log
```

报告中的内存布局图由 TikZ 命令 `\membar` 直接绘制（不必截图），用法见模板注释。
