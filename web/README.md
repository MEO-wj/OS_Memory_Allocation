# web — 演示网页（部署根目录）

Cloudflare Pages 部署要点：构建命令留空，构建输出目录填 `web`。
本地预览：直接用浏览器打开 `index.html`（无依赖、纯静态）。

## 文件

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构（输入、布局、指标、轨迹表） |
| `style.css` | 样式 |
| `core.js` | 状态模型、分配/释放、三项检查（浏览器与 Node 通用，供 `tools/` 复用） |
| `strategy.js` | 首次适应 / 最佳适应选块 |
| `cases.js` | 预置案例（与 `experiments/inputs/` 一致） |
| `app.js` | 交互、内存条渲染、指标与轨迹表、轨迹导出 |

## 功能清单（任务书要求）

- [x] 输入/编辑操作序列，切换策略（FF / BF）
- [x] 单步执行、运行到底、重置
- [x] 带地址的内存布局图 + 四项指标（空闲总量/最大块/块数/本步结果）
- [x] 失败申请与非法操作显示明确原因，并提示"状态不变"
- [x] 预置案例：两策略分歧、三种合并、仅左合并、碎片失败
- [x] 差异步标记（★ 表示该步两策略结果不同）
- [x] 三项约束检查实时显示（不重叠 / 守恒 / 合并完整）
- [x] 轨迹导出（JSONL，格式与 `experiments/traces/` 一致）
- [x] 页面注明证据来自模拟程序
