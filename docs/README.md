# docs — 文档目录索引

本目录存放项目全部说明文档与课程原始材料。建议阅读顺序如下。

| 文件 | 内容 | 读者 |
|------|------|------|
| `00-总览与提交清单.md` | 全局要求：四步实践法、演示程序要求、材料包清单、评分办法、时间安排 | 全体 |
| `01-题目五解读与原理.md` | 题目五要求逐条解读、内存模型、两种策略、合并规则、约束检查 | 全体 |
| `02-实验设计与序列草案.md` | 三组实验序列（已手算核对）、输入 JSON 格式、四项指标、推演表模板 | 分工后 |
| `03-大模型交互记录指南.md` | 提问模板、记录模板、三个易混淆概念的核验要点 | 全体 |
| `04-现场验收与答辩准备.md` | 验收应对三步法、必背要点、追问清单、提交前自查 | 答辩前 |
| `05-报告模板说明.md` | 报告模板来源（学校模板库）、选型理由、编译方法、压缩篇幅 | 写报告时 |
| `任务书/任务书.pdf` | 课程原始任务书（16 页） | 全体 |
| `任务书/任务书-文本版.txt` | 任务书的纯文本提取版，便于全文检索 | 全体 |

## 与其他目录的对应关系

- 实验结果与轨迹 → `experiments/`
- 大模型问答原文 → `model-interactions/`
- 个人分析 → `individual/`
- 演示程序 → `web/`
- 报告正文与 PDF → `report/`
