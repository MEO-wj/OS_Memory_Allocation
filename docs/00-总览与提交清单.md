# 00 · 总览与提交清单（全局要求）

> 依据：任务书第 1–4 页。本文件是**所有题目通用**的全局要求整理，
> 题目五的专项要求见 `01-题目五解读与原理.md`。

## 一、实践方法：四步闭环（必须留证据）

| 步骤 | 做什么 | 对应证据 |
|------|--------|----------|
| 1. 先提出假设 | 每位成员独立写一项判断或疑问，并说明理由 | 个人初始假设 |
| 2. 再讨论 | 向大模型给出规则与输入，要求解释依据、提出检验方法 | 关键交互记录（3–5 段） |
| 3. 做验证 | 运行程序；用手工推演、对照或反例核对关键结果 | 输入、轨迹与人工核对 |
| 4. 作判断 | 依据证据决定采纳、修改或拒绝，并说明适用条件 | 结论、修正与局限 |

**红线**：每位成员都要参与思考和验证，不能直接把模型回答当作结论。

## 二、演示程序要求（全局）

- 能**修改实验数据**、**运行算法**、展示主要过程和结果；
- 网页或本地程序均可，不要求登录、不要求调用大模型；
- 网页提供访问网址；本地程序附运行说明并配套一个演示网页；
- 若使用模拟或运行记录回放，需写明；**不能只提交截图或视频**。

推荐技术路线：GitHub 托管 + Cloudflare Pages 部署（纯静态页面即可，无需后端）。

### Cloudflare Pages 部署要点

1. 仓库推送到 GitHub；
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git；
3. 构建命令留空，**构建输出目录填 `web`**（本仓库网页在 `web/` 下，纯静态）；
4. 部署完成后得到 `https://<项目名>.pages.dev`，每次 push 自动更新；
5. 报告中记录"演示网址对应的 commit SHA"，保证线上版本与提交版本一致。

## 三、每组提交一个完整材料包

| 材料 | 具体内容 | 提交说明 |
|------|----------|----------|
| 基本信息表 | 题号、组号、成员分工、演示网址、仓库网址及**对应完整 commit SHA** | |
| 源码与运行包 | 与提交版本一致的源码压缩包、依赖说明、本地启动步骤及部署方法 | |
| 小组报告 | 建议 4–6 页：问题与假设、方法、关键实验、模型建议核验、结论与局限 | |
| 实验材料 | 本题全部专项材料，以及可读取的输入、参数、原始输出、轨迹与人工核对 | 见 docs/01 第四节 |
| 模型交互记录 | 3–5 段关键交互；每段关联学生判断、实际实验与证据位置 | 模板见 docs/03 |
| 个人分析 | 每人约半页至一页：初始假设、亲自完成的验证、认识变化及个人贡献位置 | 放 `individual/` 目录 |

打包命名：`组号_题目五_张三-李四-王五-赵六-钱七_实践项目.zip`（列出全体组员姓名）。
完整报告和个人课程材料通过课程入口提交，**不必放入公开网页**。

## 四、统一评分办法（满分 100 = 小组 70 + 个人 30）

| 评分维度 | 分值 | 分项依据 |
|----------|------|----------|
| 原理与模型 | 20 | 假设与规则 5 分；核心机制解释 10 分；适用边界与约束 5 分 |
| 实验与演示 | 30 | 实现及状态轨迹 10 分；对照、反例或故障实验及人工核对 10 分；网址演示 5 分；输入输出与本地复现 5 分 |
| 大模型使用 | 20 | 具体问题与约束 5 分；模型建议与独立证据关联 10 分；采纳判断、认识修正与局限 5 分 |
| 个人考核 | 30 | 独立解释原理及本人证据 15 分；针对输入变化提出假设或手工推算 10 分；可核对的个人贡献 5 分 |

## 五、验收方式

1. 小组演示 **5–8 分钟**，展示程序和主要实验结果；
2. 按评分表，结合提交材料和演示情况评分；
3. 网页无法访问时，可改为本地演示并说明原因；
4. 提交材料须真实，并注明参考来源。

## 六、实验记录模板（每组案例一份）

| 字段 | 填写内容 |
|------|----------|
| 案例与判断 | 案例编号、责任成员、要检验的具体判断 |
| 输入与规则 | 完整输入、参数、算法规则；适用时记录随机种子或序列 |
| 提出假设 | 预期现象、理由以及成员的初始判断 |
| 实际与核对 | 原始输出位置、人工推演、差异出现的步骤及原因 |
| 结论与边界 | 支持或推翻了什么；成立条件；仍未验证的部分 |

## 七、时间安排（建议两至三周）

- **前期**：确定分工和模型规则；每人记录初始假设；建仓库并部署最小页面；
- **中期**：实现核心算法，完成对照、反例实验，独立核对关键结果；
- **后期**：交叉复核，核对线上版本，整理证据，准备 PPT 和现场演示材料。
